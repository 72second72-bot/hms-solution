H-01 · 방법 글

캐드 도면 좌표계 5174 를 5186 으로 바꾸는 법

흔히 동경측지계라 부르는 베셀 계열의 EPSG:5174 도면을 세계측지계(GRS80)인 EPSG:5186 도면과 겹치려면, 도면을 같은 거리만큼 옮기는 이동이 아니라 점마다 새로 계산하는 캐드 좌표계 변환이 필요합니다. 같은 점은 약 10만 m 옮겨집니다. AutoCAD Map 3D · QGIS 로 바꾸는 순서와 바꾼 뒤 확인할 것을 차례로 적었습니다.

2026-11-12 작성 · 예시 숫자는 모두 지어낸 가상 필지에서 뽑았습니다.

H-01

01

좌표계 바꾸기와 좌표 이동은 다릅니다

'오토캐드 좌표 변환' 을 찾으면 UCS 나 이동(MOVE) 안내도 함께 나오지만, 셋은 하는 일이 다릅니다.

UCS
그리는 기준 축만 옮기거나 돌립니다. 객체는 고정된 세계 좌표계(WCS)의 좌표로 정의되어 그대로입니다.
이동(MOVE)
모든 객체를 같은 방향 · 같은 거리만큼 옮깁니다.
좌표계 바꾸기
같은 점을 다른 원점 · 다른 타원체 기준의 숫자로 다시 적습니다. 점마다 따로 계산하므로 옮겨지는 양이 조금씩 다릅니다.

예시용 가상 필지의 일곱 점은 수백 m 안에 모여 있는데도, 5174 에서 5186 으로 옮겨진 거리가 100,304.821 m 에서 100,304.830 m 까지 달랐습니다. '좌표변환 리습' 을 구하신다면 좌표계를 계산해 바꾸는지, 같은 거리만 옮기는지 먼저 보십시오.

02

5174 와 5186 은 무엇이 다른가

둘 다 북위 38° 를 원점으로 하는 중부원점 계열의 TM 좌표입니다. 다른 것은 측지계와 원점 값입니다.

두 좌표계 모두 원점의 축척계수는 1 입니다.
구분EPSG:5174EPSG:5186
이름한국 1985 수정 중부원점한국 2000 중부원점 2010
측지계한국 1985 (흔히 동경측지계라 부르는 베셀 계열)한국 2000 (세계측지계)
타원체Bessel 1841GRS 1980
원점북위 38° · 동경 127°00′10.405″북위 38° · 동경 127°
원점에 더하는 값동쪽 200,000 m · 북쪽 500,000 m동쪽 200,000 m · 북쪽 600,000 m

같은 점이 약 10만 m 옮겨지는 것은 원점에 더하는 북쪽 값이 50만 m 에서 60만 m 로 커졌기 때문입니다. 여기에 원점 경도와 측지계 차이에서 오는 이동이 더해져, 예시 가상 필지의 한 점은 캐드 좌표로 X(동쪽) 약 69 m, Y(북쪽) 약 100,305 m 옮겨졌습니다.

베셀에서 GRS80 으로 타원체가 바뀌어 길이와 면적도 아주 조금 달라집니다. 예시 가상 필지 242개의 면적은 평균 0.0017%(1,000 m² 당 0.017 m²) 줄었습니다.

03

프로그램별로 바꾸는 두 가지 방법

메뉴 이름은 공식 도움말의 영문판 이름입니다. 판마다 다를 수 있으니 쓰시는 판의 도움말도 함께 보십시오.

방법 1

AutoCAD Map 3D 의 좌표계 기능

준비물 · AutoCAD Map 3D. Civil 3D 도움말에도 좌표계 지정 명령(GEOCSASSIGN)은 있습니다.

  1. 새 도면을 엽니다.
  2. 바꿀 5174 도면을 첨부합니다(Home 탭 › Data › Define Drawing Set › Attach, 또는 Map Explorer 로 끌어다 놓기).
  3. 새 도면에 GEOCSASSIGN 으로 EPSG:5186 을 지정합니다.
  4. 첨부 도면에 좌표계가 없으면 ADESETCRDSYS 로 EPSG:5174 를 지정합니다. 쿼리해 온 객체가 남아 있으면 지정되지 않으니 쿼리 전에 합니다.
  5. 경계 종류가 All 인 위치 조건으로 쿼리하면, 객체가 5186 으로 바뀌어 들어옵니다.
  6. 첨부를 풀고 저장합니다. 원본 도면은 그대로입니다.
Autodesk 공식 도움말
  • 도면의 좌표계 바꾸기 (Map 3D) 영문
  • 도면 첨부하기 (Map 3D) 영문
  • 좌표계 지정 GEOCSASSIGN (Map 3D) 영문
  • 첨부 도면에 좌표계 지정 ADESETCRDSYS (Map 3D) 영문
  • 좌표계 지정 (Civil 3D) 영문
방법 2

QGIS 로 재투영해 DXF 로 내보내기

준비물 · QGIS, DXF 로 저장한 도면.

  1. DXF 를 벡터 레이어로 불러옵니다(QGIS 는 GDAL 로 읽습니다).
  2. 레이어 좌표계를 EPSG:5174 로 지정합니다(Layer ► Set CRS of Layer(s)). 값을 바꾸지 않고 '5174 자료' 라고 알려 주는 일입니다.
  3. Project ► Import/Export ► Export Project to DXF 에서 EPSG:5186 을 고르면, 레이어가 그 좌표계로 재투영되어 저장됩니다. Output layer attribute 로 Layer 필드를 고르면 원래 도면층 이름대로 나뉩니다.
  4. 결과 DXF 를 AutoCAD 에서 엽니다.

주의 · GDAL 의 DXF 안내에 따르면 읽을 때 블록은 풀리고, 해치는 무늬 없는 면이, 원 · 호는 짧은 선분이 됩니다. 문자 자리도 조금 다를 수 있어, 블록과 해치가 많은 도면은 다시 손보셔야 할 수 있습니다.

QGIS · GDAL 공식 문서
  • 좌표계 다루기 (QGIS) 영문
  • DXF 파일로 내보내기 (QGIS) 영문
  • DXF 를 읽고 쓰는 방식 (GDAL) 영문
04

AutoCAD 안에서 바로 바꾸기

도면을 다른 프로그램으로 내보냈다 다시 불러오지 않고 열어 둔 도면에서 바로 바꾸려면, AutoCAD 에 플러그인으로 올라가는 캐드 좌표 변환 프로그램인 HMS 좌표변환을 쓰실 수 있습니다.

  1. 01

    명령창에 HMSCRS 를 입력합니다

    먼저 Solution Center 에서 설치하고 [로드]를 누릅니다.

  2. 02

    원본 EPSG:5174 · 변환 EPSG:5186 을 고릅니다

    [지정점 좌표 미리보기]로 바뀔 좌표를 먼저 보실 수 있습니다.

  3. 03

    옮길 대상과 원본을 남길지 정합니다

  4. 04

    [좌표변환 실행]을 누릅니다

    무엇을 몇 개 옮겼는지 작업 로그에 남습니다.

해치와 그리기 순서를 지키고, 잠긴 도면층은 옮기는 동안만 풀었다가 다시 잠급니다. 원과 호는 곡선 허용오차(기본 0.01 m)에 맞춰 잘게 나눈 폴리선으로 옮깁니다.

05

바꾼 뒤 확인할 것

  • 원본을 먼저 따로 저장해 둡니다

    원본을 직접 바꾸는 방식이면 실행 전에 사본을 꼭 따로 저장해 두십시오.

  • 한 점의 좌표를 견줍니다

    도곽 모서리처럼 알아보기 쉬운 점을 바꾸기 전후로 ID 명령으로 잽니다. ID 는 UCS 기준 값을 보여 주므로 UCS 를 세계(WCS)로 둡니다. 캐드의 X 는 동쪽이라 측량 성과표의 X(북쪽)와 반대입니다. 예시 가상 필지의 한 점은 X 200,544.992 · Y 500,229.918 이 X 200,613.801 · Y 600,534.725 가 되었습니다.

  • 5186 도면과 겹쳐 봅니다

    같은 자리의 5186 도면과 아직 약 10만 m 어긋나면, 바꾸기 전 도면을 겹쳤거나 이미 5186 이던 도면을 한 번 더 바꾼 것일 수 있습니다.

  • 면적표를 다시 봅니다

    면적이 아주 조금 달라지므로, 면적표가 붙은 도면은 다시 재어 봅니다.

  • 곡선을 살핍니다

    방법에 따라 원과 호가 폴리선이나 선분으로 바뀝니다. 곡선이 꼭 필요한 곳은 확인하십시오.
